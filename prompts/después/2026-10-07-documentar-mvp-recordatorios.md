## Prompt adicional

No se recibió un prompt humano adicional para la revisión. Se verificó el
resultado contra los prompts reales registrados en prompts/antes/.

## Comprobaciones solicitadas a la revisión

- No debe quedar un flujo donde cada usuario conecte una cuenta de WhatsApp.
- README, reglas, spec y ADR deben usar el mismo contrato { phone, message }.
- El worker debe ser durable y la notificación interna obligatoria.
- Los canales externos deben fallar de forma independiente.
- Los documentos no deben afirmar que ya existe código o despliegue.
